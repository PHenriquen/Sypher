# Parent-name clearance checklist

The company architecture should not depend on a parent name being legally or commercially available. Before investing in a domain, custom wordmark, company registration or trademark filing, clear the parent name separately from the visual system.

## Minimum checks

1. Search exact and phonetically similar technology-company names in Brazil.
2. Search international technology/software businesses using the same word.
3. Search INPI trademark records across relevant software, technology, hardware, entertainment and business classes.
4. Check `.com`, `.com.br` and realistic fallback domains.
5. Check GitHub, LinkedIn, Instagram, X, YouTube and major app stores.
6. Search the name with terms such as `AI`, `software`, `systems`, `labs`, `engineering`, `games` and `technology`.
7. Check whether an existing creator/public figure dominates search results for the same name.
8. Avoid a name that requires adding `Tech`, `Solutions`, `Digital` or a random suffix just to become findable.

## Decision rule

A name does not need to be globally unique, but it should be distinct enough in the same commercial/technical field that:

- users do not routinely confuse the companies;
- search results can realistically be owned over time;
- product launches do not inherit another brand's reputation;
- a future trademark/domain strategy remains plausible.

## Current status

The architecture and identity work can continue under a working parent name. Treat domain purchases, formal filings and cross-repository endorsement as the point where clearance becomes mandatory.
