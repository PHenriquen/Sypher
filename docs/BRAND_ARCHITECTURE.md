# Zypher brand architecture

This document is intentionally provisional. It defines the structure before locking final logos or division marks.

## Company role

Zypher is the parent brand. It should stay broad enough to support products across software, AI, physical computing and interactive work without forcing every project into the same visual personality.

## Divisions

| Division | Purpose | Signature color | Visual motif |
| --- | --- | --- | --- |
| Zypher Labs | Research, prototypes and experimental R&D | `#8C7BFF` | Orbit / field |
| Zypher Intelligence | AI, assistants, agents and intelligent automation | `#43CFFF` | Core / halo |
| Zypher Products | SaaS and general digital products | `#52D9AE` | Modules / grid |
| Zypher Systems | Industrial and operational software | `#3973FF` | Hub / signal |
| Zypher Engineering | Hardware, IoT, embedded and physical systems | `#E99A55` | Interlock / structure |
| Zypher Interactive | Games and digital experiences | `#E05268` | Echo / sigil |

## Current lineage

- **Illume** → Zypher Intelligence
- **Nodi** → Zypher Products
- **SincroHub** → Zypher Systems
- **Manopla Inteligente** → Zypher Engineering
- **Réquiem** → Zypher Interactive
- Early concepts and uncommitted experiments → Zypher Labs

## Visual rule

The divisions should feel related through disciplined geometry, typography, spacing and reduction, not by reusing the same symbol with six different colors. Each division should eventually have a distinct mark that still belongs to the same system.

The parent Zypher logo is not locked yet. The website therefore uses a typographic wordmark until the final mark is chosen.
