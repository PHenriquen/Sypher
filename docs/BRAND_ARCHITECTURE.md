# Sypher brand architecture

This document is intentionally provisional. It defines the structure before locking final logos or division marks.

## Company role

Sypher is the parent brand. It should stay broad enough to support products across software, AI, physical computing and interactive work without forcing every project into the same visual personality.

## Divisions

| Division | Purpose | Signature color | Visual motif |
| --- | --- | --- | --- |
| Sypher Labs | Research, prototypes and experimental R&D | `#8C7BFF` | Orbit / field |
| Sypher Intelligence | AI, assistants, agents and intelligent automation | `#43CFFF` | Core / halo |
| Sypher Products | SaaS and general digital products | `#52D9AE` | Modules / grid |
| Sypher Systems | Industrial and operational software | `#3973FF` | Hub / signal |
| Sypher Engineering | Hardware, IoT, embedded and physical systems | `#E99A55` | Interlock / structure |
| Sypher Interactive | Games and digital experiences | `#E05268` | Echo / sigil |

## Current lineage

- **Illume** → Sypher Intelligence
- **Nodi** → Sypher Products
- **SincroHub** → Sypher Systems
- **Manopla Inteligente** → Sypher Engineering
- **Réquiem** → Sypher Interactive
- Early concepts and uncommitted experiments → Sypher Labs

## Visual rule

The divisions should feel related through disciplined geometry, typography, spacing and reduction, not by reusing the same symbol with six different colors. Each division should eventually have a distinct mark that still belongs to the same system.

The parent Sypher logo is not locked yet. The website therefore uses a typographic wordmark until the final mark is chosen.
