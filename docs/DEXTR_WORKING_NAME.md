# DEXTR — working product name

`DEXTR` is the current working product name for the repository still named `Manopla-Inteligente`.

## Why change the display name

`Manopla Inteligente` describes the prototype literally, but reads more like an academic/project label than a product brand. The product identity should be able to survive beyond one physical form factor.

## DEXTR direction

The name is derived from dexterity / dexter: hand skill, precision and controlled interaction. It connects naturally to a wearable or physical control interface without putting `smart`, `IoT`, `tech` or `gauntlet` in the brand.

Provisional lockup:

**DEXTR — Sypher Engineering**

The GitHub repository is not renamed yet. Do not change package identifiers, URLs or historical references until the working name is explicitly approved and checked for naming/trademark conflicts.
