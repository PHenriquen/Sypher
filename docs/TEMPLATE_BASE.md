# Website template base

The current Sypher homepage structure is adapted from the **Finwise: SaaS Landing Page** starter listed in the Vercel Templates gallery.

- Vercel template: `vercel.com/templates/saas/finwise-saas-landing-page`
- Upstream repository: `nexi-launch/finwise-landing-page`
- Upstream license: MIT, as stated by the template documentation

Sypher does not reuse Finwise branding, product copy, imagery or site identity. The starter is used as a structural and frontend-engineering base: centered hero composition, responsive marketing-site rhythm, modular sections, Tailwind utilities and Framer Motion transitions. All Sypher content, division architecture, marks, colors and project presentation remain project-specific.
