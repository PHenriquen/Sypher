# Sypher identity assets

This folder is the source of truth for the working brand system.

- `tokens.json` — machine-readable palette and identity names.
- `/public/brand/sypher.svg` — parent working mark, **Cipher Ribbon**.
- `/public/brand/divisions/*.svg` — division marks.
- `/public/brand/projects/*.svg` — project web marks.
- `/docs/BRAND_SYSTEM.md` — full architecture and usage rules.

## Status

The division architecture is considered stable enough for product and website work. The parent name and master corporate wordmark still require market/legal clearance before being treated as permanent.

## Asset rule

Core SVG files contain no required glow, gradients or filters. Effects belong to presentation layers so every mark remains usable at small scale, in print and in one color.
